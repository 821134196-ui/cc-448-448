# 共享冷库 · 租格与温度计费平台

管理库区、货格、租户、货品批次、入库重量、目标温区、租用时段、开门记录、
温度采样、移格申请与费用结算的一体化平台。**全部经营数据均为虚构**，
仅使用 Python 标准库（无需 pip 安装），SQLite 持久化，零前端依赖。

## 一条命令启动（含预约冲突 + 温度异常样例）

```bash
python3 run.py --demo
```

打开 http://127.0.0.1:8000 ，演示数据会重建，包含：

- 两笔预约争抢冷冻区最后一个合适货格（F-07）——**仅一笔确认成功，另一笔返回冲突**；
- C-01 货格的**温度越界 + 断电 + 门未关**回填采样，监控线程继续产生实时读数；
- C-02 已退库账单（含越界补偿，**等待财务复核**）与 AC-03 已结清账单；
- 同温区已完成移格（C-03→C-04）、跨温区待审批移格（F-02→AC-05）；
- 管理员手工改温（AC-01，强制填写原因）。

其他启动方式：`python3 run.py`（沿用现有数据）、`--demo --seed-only`（只播种）、
`--no-monitor`（关闭后台采样）、`--port 9000`。

## 核心业务规则

- **预约确认**时锁定具体货格容量与目标温区；两笔预约并发争抢同一货格时，
  容量判定在 `BEGIN IMMEDIATE` 事务内完成，只有一笔成功。
- **入库复核通过**才创建租期（lease）并开始计费；复核不通过不放行、不计费。
- **移格**：同温区空格直接执行；跨温区必须管理员重新确认，计费温区随之切换。
- **退库清点**生成不可变费用快照：计费区间按时间轴（移格时刻）拆开，
  含占格时长租金、重量附加费（超 300 kg/m³ 标准密度部分）、
  超容/临时降温/门未关/渗漏/提前退租加收，以及越界/断电补偿减免；
  **已结账租期不可重新打开**，重复退库幂等返回原账单。
- **负数减免必须财务逐项复核**，全部核准后账单才可支付。
- 异常留痕七类：超容、临时降温、温度越界、断电补偿、门未关、货品渗漏、提前退租。

## 数据与存储

- SQLite：`data/coldstorage.db`（租期、预约、采样值、开门记录、账单快照等，
  可用 `CS_DATA_DIR` 环境变量改位置）。
- 货品照片：`data/photos/`（本地文件，入库批次可上传）。
- 进程内任务：`Monitor` 线程按节拍为在租货格产生模拟读数，并扫描越界/断电/
  门未关时长（越界按分钟积分补偿，带 120 秒抗抖宽限）。
- 模拟适配器：`coldstorage/adapters.py`（门磁、温度/断电读数、情景注入与历史回填）。

## 测试

```bash
python3 -m unittest tests.test_platform -v
```

覆盖：容量锁定（含真实线程争抢）、温区与移格约束、计费边界
（计费起点、重量阈值、越界/断电积分、门未关宽限、跨区时间轴切分）、
结算幂等（重复退库、已结账不可改、减免复核后才支付）、租户隔离（HTTP 层 403）。

## 界面

配色为冰白、蓝绿、深紫灰；库区格位图按温区**纵向分组**并显示剩余容积与占用比例；
温度曲线以**清晰阈值带**呈现（上下限虚线、目标点线、断电斜纹、门开启时段、
越界红点双重编码、十字线 tooltip、可切数据表），不使用装饰性面积图；
账单明细将计费区间按**时间轴**逐段展开，异常减免紧邻其对应区间显示。
