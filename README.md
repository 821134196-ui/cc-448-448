# 霜格云仓 · 共享冷库租格与温度计费平台

管理库区、货格、租户、货品批次、入库重量、目标温区、租用时段、开门记录、温度采样、
移格申请与费用结算。**全部为虚构经营数据**，仅用 Python 3.10+ 标准库实现
（SQLite + http.server），零第三方依赖。

## 一条本地命令启动

```bash
python3 run.py --demo --serve
# 打开 http://127.0.0.1:8000/
```

该命令会重建 `data/coldstore.db`，写入：

- **预约冲突样例**：两笔预约争抢 A 区最后一个兼容货格，仅一笔成功，败者保持待确认；
- **温度异常样例**：近 30 小时采样曲线中含临时降温、断电升温、越界（-12.4℃）窗口；
- 已退库待结账账单（含超容、断电补偿已批、越界补偿待财务复核）；
- 已结账账单（含提前退租，快照关闭不可重开）；
- 跨温区移格待重新确认、门未关、货品渗漏、管理员手工改温留痕。

演示登录（一键选择，无密码）：

| 身份 | 令牌 | 能做什么 |
|---|---|---|
| 管理员 库管·孟衡 | `tok-admin` | 确认预约、入退库复核、移格确认、门磁、渗漏、手工改温 |
| 财务 费谨 | `tok-finance` | 减免复核、追加减免、结账 |
| 租户（冰鲜达/海味坊/雪原） | `tok-tenant1..3` | 只能看自己的货格、租约与照片 |

仅建样例不启服务：`python3 run.py --demo`；运行测试：

```bash
python3 -m unittest tests.test_platform -v
```

## 核心业务规则

1. **预约确认即锁定**：按目标温区匹配能覆盖它的库区，在事务
   （`BEGIN IMMEDIATE`）中选取空格并扣减容量；并发争抢时后到者报
   `CellCapacityError`，容量不会被双占。
2. **入库复核通过才计费**：`actual_start` 是计费起点；实测容积超货格容量即开启
   “超容”异常并按占格费 30% 加收。
3. **移格**：同温区空格直接移位；跨温区（如深冷→冷藏）进入待确认，
   管理员重新确认后才执行，且计费时间轴以确认时刻为界、各区按本区费率结算。
4. **退库清点结束生成费用快照**：占格时长 + 重量附加费 + 异常附加
   （超容/临时降温）− 财务批准的减免；早于计划结束 1 小时以上记“提前退租”。
5. **异常补偿**：断电按区间费用 50%、温度越界按 30% 自动生成**待财务复核**的减免，
   账单页上减免紧邻对应时间区间；未复核完不能结账。
6. **结账幂等且不可重开**：重复结账返回同一快照、不重复收费；已结账租约不能
   再退库、移格、追加减免或重算快照。
7. **留痕**：超容 / 临时降温 / 温度越界 / 断电补偿 / 门未关 / 货品渗漏 /
   提前退租 / 手工改温（必填原因）全部写入 `incidents` 与 `audit_log`。
8. **租户隔离**：租户只能访问自己的租约与照片，越权返回“无权访问”；
   财务/管理员操作有角色校验。

## 页面

- **库区格位图** `/cells`：按库区纵向分组，显示温区、费率、货格占用/剩余容积与超容标记；
- **预约日历** `/calendar`：月视图标注入库（蓝）、退库（紫）与租用区间；
- **租约详情** `/reservations/<id>`：入退库复核、移格、门磁、渗漏、照片与账单工作台；
- **温度曲线** `/temperature`：SVG 折线，**清晰阈值带**——冰青带为合格温区、
  紫虚线为库区物理边界、红点为越界采样（带十字线 tooltip），不是装饰面积图；
- **异常留痕** `/incidents`：全部异常列表 + 管理员手工改温（原因必填）；
- **财务复核台** `/finance`：待批减免与费用快照。
- 账单明细把计费区间沿**时间轴逐段拆开**，每段标注类型、小时、重量与金额，
  减免芯片紧邻其对应区间显示。

## 进程内任务与模拟适配器

`coldstorage/adapters.py`：

- `SimTempAdapter`：按库区温区生成带小幅波动的读数，可注入断电（向 18℃ 漂移）、
  临时降温和越界情景；
- `SimDoorAdapter`：成对产生开/关门磁事件，开门超过 5 分钟自动记“门未关”；
- `MonitorLoop`：后台线程周期采样并判定越界/断电/降温开合，异常按在租货格
  归属到具体租约（断电期间的高温不重复记越界）。

## 数据与文件

```
data/coldstore.db      # SQLite：租期、采样、开门、异常、计费区间、快照
data/photos/           # 本地货品照片（演示为 SVG 占位图），库里只存路径
coldstorage/
  db.py        表结构与事务
  models.py    状态/费率/错误类型
  services.py  预约锁定、复核、移格、异常、费用快照、结账
  adapters.py  模拟门磁/温度适配器 + 监测线程
  seed.py      虚构演示数据
  webapp.py    Web 路由与页面
run.py         启动入口
tests/test_platform.py  37 个测试
```

测试覆盖：容量锁定（含并发争抢）、温区约束（不兼容/同区直移/跨区确认）、
计费边界（起停时刻、超容、断电拆段、越界补偿、临时降温、跨区费率、提前退租）、
结算幂等与关闭后锁定、服务层与 HTTP 层租户隔离、监测任务开合判定。
